# Offline geography labels

Country display names: Unicode CLDR (German), Unicode License v3. Regions: GeoNames admin1CodesASCII, CC BY 4.0; attribution: GeoNames, https://www.geonames.org/. Source data were reduced to code/name pairs; hashes and source URLs are in source.json. Original region spellings are retained. These references translate existing codes; they provide no geographic boundary lookup.

Included in the binary and in the app’s GeoLabels license notices. No runtime network request is needed. Unknown codes fall back to their code or “Region <code>”. Refresh the checked-in reference files deliberately, retaining notices and source hashes.
